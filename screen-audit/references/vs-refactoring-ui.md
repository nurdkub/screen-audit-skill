# screen-audit и refactoring-ui

Скилл вырос из теста скилов визуального дизайна 16.10.2026 (прототип
`2026-10-ui-skills-comparison`). Вывод теста: чужие скилы тянут добавить на экран лишнее
и спорят с токенами, а полезная часть refactoring-ui — **формат проверки**: короткий список
вопросов «да/нет», оценка из 10 и правка у каждого «нет». Эту часть и взяли; знания о том,
каким должен быть ответ, — из базы Square.

## Что взято

| У refactoring-ui | В screen-audit |
|---|---|
| Quick Diagnostic: 8 вопросов «да/нет» | 10 вопросов, оценка = число «да» |
| Оценка и «что закрыть до 10/10» | то же, разделом «Чтобы дойти до 10» |
| Blur test | пункт 1 «Прищур» |
| Grayscale first | пункт 2 «Серый» — только как проверка, не как процесс верстки |
| «Зазор между группами больше, чем внутри» | пункты 4–5: шов и лестница по родству |
| Labels de-emphasized | пункт 7, рычагами Square |
| Constrain text width | пункт 9 |
| Contrast minimums | заменено пунктом 10 «Роль токена цвета»: контраст выверила ДС, проверяется только выбор ступени |
| Shadow scale | заменено пунктом 3 «Слои»: глубина в Square — слоями, а не тенями |

## Что спорит со Square — и ответ ДС

| Совет refactoring-ui | Ответ Square |
|---|---|
| Шкала отступов 4/8/16/24/32/48/64 px | Шкалы `gap` / `paddings` / `margin`, ступень выбирается по роли (`screen.md`), а не по числу |
| «Начни с избытка воздуха и убавляй» | Плотность Documentolog выше: `size="small"`, шов `gap/04`. Группу держит белая плоскость, а не воздух |
| Разгонять зазор между группами | Между плоскостями — шов `gap/04`, разделяет заливка. Разгон — только высота карточки в сетке |
| Своя палитра 50–900, подкрашенные серые | Палитру держат токены mapped, своих цветов нет |
| Тени для глубины, `shadow-sm` на кнопках | Теней в разметке нет; тень есть только у накладок и задана компонентом |
| Скругления, «bleed» картинок за край карточки | Углы прямые — правило айдентики |
| Капс-подпись мелким кеглем | Такого стиля в ДС нет; подпись тише цветом текста или `body/s` |
| Модульная шкала кегля, две гарнитуры | Набор текстовых стилей и гарнитура задаются темой продукта |
| «Выделенная крупная цифра» на дашборде | В продукте `h1` / `h2` запрещены, приёма нет — вопрос автору ДС |
| Иллюстрация в каждом пустом состоянии | Только `Illustration` из набора; подходящей нет — пустое состояние текстом |
| Разнообразить карточки в ленте по размеру | Сетка и плоскости одинаковые; главное выделяется местом и состоянием |
| Поднять контраст серого текста до gray-700 | Контраст токенов и компонентов — зона ДС, на экране не чинится |

## Почему не дописать правила в сам refactoring-ui

Скилл чужой и обновляется отдельно: правка в нём уедет при обновлении, а его общие советы
продолжат срабатывать рядом. Свой скилл с явным «вместо refactoring-ui» в описании
перехватывает запрос на экранах полигона и не даёт двум шкалам спорить.
