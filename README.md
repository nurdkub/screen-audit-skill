# screen-audit

Скилл для Claude Code: проверяет готовый экран прототипа на дизайн-системе Square, сам исправляет найденное и проверяет экран заново.

Формат проверки взят у скилла refactoring-ui (автор — wondelai) — вопросы «да/нет» и оценка из 10. Ответы на вопросы — из правил Square: шкалы отступов, слоёв, текстовых стилей и токенов. Своих пикселей, палитры, теней и шрифтов у скилла нет.

> **Скилл на тесте.** Сам по описанию он не включается — только командой `/screen-audit`. Работает в репозитории полигона Square: опирается на его `docs/screen.md` и токены.

## Как работает

1. **Ищет нарушения ДС** — чужие цвета и компоненты, скругления и тени, не та тема для продукта. Исправляет сразу.
2. **Ищет ИИ-приёмы** — полосу сбоку, капс, иконку в кружке и всё, по чему видно сгенерированный дизайн. Заменяет решениями Square.
3. **Смотрит на экран глазами** — на широком и узком экране, размытым и без цвета. Глаз главнее числа.
4. **Отвечает на 14 вопросов** — 10 о строе экрана, 4 о чистоте — и ставит оценку.
5. **Сам исправляет**: сначала убирает лишнее, потом меняет, добавляет только в крайнем случае. Правит только файлы прототипа.
6. **Проверяет заново** — до трёх кругов — и пишет отчёт: оценка до и после, что исправлено, вопросы автору ДС.

Цвета скилл не меряет: значения и контраст выверила ДС. Он проверяет, та ли роль токена выбрана — `primary`, `secondary` или `tertiary`.

## Установка

Скопируйте папку `screen-audit` в один из каталогов скилов Claude Code:

- `~/.claude/skills/` — скилл будет у вас во всех проектах;
- `.claude/skills/` в репозитории полигона — скилл будет у всех, кто работает с полигоном.

Скилы читаются при старте сеанса: откройте новый чат после копирования.

## Запуск

```
/screen-audit src/prototypes/<папка прототипа>
```

Только проверка, без правок, — допишите «только проверь, ничего не меняй».
